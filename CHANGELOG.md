# Changelog

Все заметные изменения проекта фиксируются в этом файле.

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [Semantic Versioning](https://semver.org/lang/ru/spec/v2.0.0.html).

## [Unreleased]

### Added

- Workflow `Release`: после зелёного CI ставит тег `vX.Y.Z` и GitHub Release на
  каждый коммит `chore(release): X.Y.Z` без тега.
- Деплой на Railway: `.railway/railway.ts` описывает сервис из `Dockerfile`, одну
  реплику, healthcheck и том `/data`; деплой из `main` ждёт зелёного CI.

### Changed

- Docker: стадия `runtime` теперь последняя и собирается без `--target`; порт берётся
  из `PORT`; инструкция `VOLUME` убрана; контейнер отдаёт том пользователю `app` и
  запускает сервис от него.
- `BASE_URL` по умолчанию берётся из `RAILWAY_PUBLIC_DOMAIN`; без `SECRET_SALT` соль
  генерируется при первом запуске и хранится в `DATA_DIR`.

### Fixed

- После смены домена открытки рисуются заново: кэш `og:image` раскладывается по
  папкам доменов, а не отдаёт старые картинки с прежним адресом.

## [0.6.0] - 2026-10-23

### Added

- Приёмочные тесты: прогон всего словаря по нужным формам, фазз-тест 10 000 фраз на
  пресет, 30 золотых фраз со снапшотом (`--update-golden`).
- Docker: образ на `python:3.12-slim` с непривилегированным пользователем и
  `HEALTHCHECK`, стадия `test` для прогона тестов в контейнере, `docker-compose.yml`
  с именованным томом `/data`.
- CI собирает образ и прогоняет тесты внутри контейнера.

### Changed

- Выборка слов идёт по заранее посчитанным весам с отбраковкой: ~1 мс на фразу
  вместо 7–42 мс.

## [0.5.0] - 2026-10-23

### Added

- Главный экран: слот-машина с анимацией прокрутки незакреплённых слов, замки и
  перегенерация отдельного слова, пресеты, тоны, «Дикий словарь», Пробел.
- Кнопки «Скопировать как промпт», «Промпт для художника», «В зал славы ❤️»,
  «Поделиться» (Web Share API на телефоне), «Скачать открытку».
- Лента «Зал славы» / «Прямой эфир» с подгрузкой по курсору и оптимистичными лайками.
- Страница `/s/{slug}` с OpenGraph и Twitter Card и кнопкой «Сгенерировать свою».

### Fixed

- «Бабушкин» больше не ставится к чувствам.

## [0.4.0] - 2026-10-23

### Added

- Открытки на Pillow: 1200×630 для `og:image` и 1080×1080 для скачивания, подбор кегля
  под 60–75% высоты поля, тёмный фон с шумом и виньеткой, акцент по тону.
- `GET /api/og-image/{slug}.png?format=wide|square` с вечным файловым кэшем.
- Шрифты PT Serif и PT Sans (OFL) в репозитории.

## [0.3.0] - 2026-10-23

### Added

- SQLite в WAL-режиме: таблицы `words`, `phrases`, `saved_ideas`, `likes`; идемпотентная
  загрузка словаря по хэшу файла при старте и скриптом `init_words.py`.
- API: `POST /api/generate`, `GET /api/phrase/{slug}`, `POST /api/save`,
  `POST /api/like/{slug}`, `GET /api/feed`, `GET /healthz`.
- Лимиты: 10 генераций в секунду и 30 лайков в минуту на клиента.

## [0.2.0] - 2026-10-23

### Added

- Морфологический движок: шесть пресетов (Сюжет, Конфликт, Абсурд, Тайна, Завязка,
  Логлайн), согласование прилагательных со своим существительным, винительный по
  одушевлённости, управление глаголов, местоимения и «должен/должна» по «Кто».
- Взвешенная выборка слов: веса ярусов, поправка на частотность, окно недавних слов,
  штраф за частые выпадения, тематическая сцепка по тону.
- Замки и перегенерация одного слова, детерминированная генерация по `seed`,
  детерминированный `slug` из ID слов и параметров формы.
- Метки применимости прилагательных (+feel, -actor, -object).
- Типограф: неразрывные пробелы после коротких слов, тире.

### Fixed

- Убраны глаголы, которым нужен только абстрактный объект («рассказать табакерку»).

## [0.1.0] - 2026-10-23

### Added

- Каркас репозитория: `pyproject.toml`, линтер ruff, pytest, pre-commit, CI.
- Морфологическая обёртка над pymorphy3: выбор разбора леммы, склонение,
  второй предложный падеж, формы предлогов «в/во», «о/об», «с/со», «к/ко».
- Курируемое ядро словаря (~2000 лемм в 7 категориях) с тонами, предлогами мест
  и управлением глаголов; стоп-лист.
- Офлайн-сборщик `tools/build_lexicon.py` и собранный `data/lexicon.jsonl`
  с ярусами core / extended / wild (~24 700 лемм).
