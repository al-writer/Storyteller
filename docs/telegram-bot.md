# Telegram-бот: проект

Второй клиент генератора сюжетов, рядом с браузерным. Умеет всё то же, что главный
экран и лента: крутить фразу, закреплять и менять отдельные слова, выбирать пресет, тон
и «Дикий словарь», копировать промпт, присылать открытку, отправлять в зал славы,
лайкать и делиться. Сверх того — inline-режим: фразу можно вставить в любой чат.

## Архитектура

**Бот живёт в том же процессе, что и веб.** Отдельный сервис пришлось бы ходить в
HTTP API, а лимиты и SQLite и так рассчитаны на один процесс (`replicas: 1`). В одном
процессе бот берёт `app.state.engine`, `app.state.db` и лимитеры напрямую, второго
контейнера и второго тома не нужно.

- Библиотека — **aiogram 3**: асинхронная, встраивается в event loop uvicorn, есть
  фабрики `CallbackData` с проверкой длины 64 байта.
- Доставка обновлений — **webhook** `POST /tg/webhook`. Telegram подписывает запрос
  заголовком `X-Telegram-Bot-Api-Secret-Token`, без верного секрета — 403. Webhook
  ставится в `lifespan`, если задан токен и `BASE_URL` — HTTPS. Локально, без
  публичного адреса, бот работает в режиме long polling фоновой задачей в том же
  `lifespan`.
- Без `TELEGRAM_BOT_TOKEN` бот выключен, веб работает как раньше.

### Общий сервисный слой

Логика из роутов `app/main.py` переезжает в `app/service.py`, и её вызывают оба
клиента:

| Функция | Сейчас в роуте | Что делает |
| --- | --- | --- |
| `generate(state, who, params)` | `/api/generate` | лимит, `engine.generate`, `remember_phrase` |
| `load(state, slug)` | `stored_phrase` | фраза из базы и её пересборка из ключа |
| `like(state, who, slug)` | `/api/like` | лимит, `save_idea` + голос |
| `card_path(state, slug, format)` | `/api/og-image` | путь к PNG, рисует при промахе кэша |
| `feed(state, sort, offset, limit)` | `/api/feed` | лента |

Ошибки — свои исключения (`TooFast`, `NotFound`, `Gone`); веб превращает их в 429/404/410,
бот — во всплывающие подсказки.

### Модули

```
app/bot/
  __init__.py     # создание Bot/Dispatcher, setup в lifespan, webhook-роут
  callbacks.py    # схемы callback_data
  keyboards.py    # все клавиатуры
  render.py       # текст сообщения из токенов фразы (HTML)
  handlers.py     # команды, нажатия, inline-запросы
```

## Кто пользователь

- Голосующий: `voter_hash = sha256(salt | "tg:" + user_id)`, ключ лимитов — первые 32
  символа, как у веба. Голос из бота и голос из браузера — два разных голоса, связывать
  аккаунты не нужно.
- Настройки пользователя — новая таблица:

```sql
CREATE TABLE IF NOT EXISTS tg_users (
    user_hash  TEXT PRIMARY KEY,   -- тот же voter_hash, сырой user_id не храним
    tone       TEXT NOT NULL DEFAULT 'auto',
    wild       INTEGER NOT NULL DEFAULT 0,
    recent     TEXT NOT NULL DEFAULT '[]',  -- последние 40 ID слов, как в localStorage
    updated_at REAL NOT NULL
);
```

## Состояние фразы — в кнопках

У каждой фразы есть `slug`, а по нему из базы восстанавливаются пресет и все слоты
(`slots_from_key`). Закреплённые слова — битовая маска индексов слотов (8 слотов →
число до 255). Значит, всё состояние сообщения помещается в `callback_data`:

```
g:Ab12Cd34Ef:5        крутить, закреплены слоты 0 и 2
```

Сессий в памяти нет: кнопки старых сообщений работают и после рестарта, и через неделю.
Тон и «Дикий словарь» — настройки пользователя, а не сообщения, они в `tg_users`.

### Схема `callback_data`

| Префикс | Поля | Действие | Ответ |
| --- | --- | --- | --- |
| `g` | slug, mask | Крутить с закреплёнными | новое сообщение |
| `r` | slug, mask, i | Сменить только слово `i` | правка сообщения |
| `l` | slug, mask, i | Закрепить/открепить слово `i` | правка сообщения |
| `v` | slug, mask, view | Переключить экран: `m` главный, `w` слова, `p` пресеты, `t` тон | правка клавиатуры |
| `p` | slug, preset | Сменить пресет | новое сообщение |
| `t` | slug, mask, tone | Выбрать тон | правка клавиатуры |
| `x` | slug, mask | Включить/выключить «Дикий словарь» | правка клавиатуры |
| `k` | slug | В зал славы + лайк | подсказка, счётчик на кнопке |
| `c` | slug, kind | Промпт `story` / `art` | новое сообщение |
| `o` | slug | Открытка | фото |
| `b` | slug | Взять за основу (все слова закреплены) | новое сообщение |
| `f` | sort, offset | Лента: `t` топ / `n` новое | правка сообщения |

Самая длинная строка — `r:` + slug 16 + маска + индекс ≈ 25 байт из 64.

## Экраны и кнопки

### Фраза — главный экран

```
Сюжет · Мрачный

Старый <b>рыбак</b> чинит ржавый ключ в заброшенном маяке,
испытывая тихую тоску.
```

Текст проходит через `typograph`, закреплённые слова — жирным. В заголовке пресет и,
если он есть, тон фразы.

```
[            🎰 Крутить            ]
[ 🔒 Слова ]  [ 📚 Пресет ]  [ 🎭 Тон ]
[ ✍️ Промпт ] [ 🎨 Художнику ] [ 🖼 Открытка ]
[ ❤️ 3 ]           [ ↗️ Поделиться ]
```

- **Крутить** присылает новое сообщение, незакреплённые слова меняются. Закрепления
  переезжают в новое сообщение через маску. У предыдущего сообщения клавиатура
  сворачивается до `[ ❤️ ] [ ↗️ Поделиться ]`. Так переписка становится блокнотом
  находок, а живой остаётся только последняя фраза.
- **❤️ N** отправляет в зал славы и ставит голос (как «В зал славы ❤️» на сайте).
  Подсказка: «Фраза в зале славы ❤️» или «Вы уже голосовали». Число на кнопке
  обновляется.

### Слова

Тот же текст, клавиатура заменяется:

```
[ 🔓 старый  ] [ 🔄 ]
[ 🔒 рыбак   ] [ 🔄 ]
[ 🔓 чинит   ] [ 🔄 ]
[ 🔓 ржавый  ] [ 🔄 ]
[ 🔓 ключ    ] [ 🔄 ]
[ 🔓 маяке   ] [ 🔄 ]
[ 🔓 тихую   ] [ 🔄 ]
[ 🔓 тоску   ] [ 🔄 ]
[ 🎰 Крутить ] [ ← Готово ]
```

- На кнопке — слово в той форме, в какой оно стоит во фразе (`SlotOut.text`).
- Нажатие на слово закрепляет или открепляет его: текст перерисовывается с новым
  жирным, маска в кнопках меняется.
- 🔄 меняет только это слово, сообщение правится на месте (`reroll_index`, остальные
  слоты передаются как закреплённые — как на сайте).
- «Крутить» прямо отсюда, чтобы не возвращаться на главный экран.

### Пресет

```
[ ✓ Сюжет ] [ Конфликт ] [ Абсурд ]
[ Тайна ] [ Завязка ] [ Логлайн ]
[ ← Назад ]
```

Выбор пресета сразу присылает новую фразу в нём, закрепления сбрасываются (как на
сайте).

### Тон и словарь

```
[ ✓ Авто ] [ Мрачный ] [ Сказочный ]
[ Кибер ] [ Город ] [ Миф ]
[ 🌀 Дикий словарь: выкл ]
[ 🎰 Крутить ] [ ← Назад ]
```

Настройка сохраняется в `tg_users` и действует со следующего прокручивания; галочка
переезжает сразу.

### Промпт

«✍️ Промпт» и «🎨 Художнику» присылают отдельное сообщение с текстом из
`PROMPT_TEMPLATES` в блоке `<pre>` — в Telegram он копируется одним нажатием. Если
промпт короче 256 символов, под ним ещё кнопка `copy_text` «📋 Скопировать». Длиннее
Telegram такую кнопку не принимает, а промпт с фразой выходит на 170–300 символов, поэтому
основной способ — `<pre>`.

### Открытка

Квадратная открытка (`format=square`) отправляется фото. Файл берётся из того же кэша
`og`, что у веба, и загружается байтами, так что работает и локально без публичного
адреса. `file_id` из ответа Telegram запоминается в памяти по slug: повторная отправка
— без загрузки.

### Поделиться и inline-режим

«↗️ Поделиться» — кнопка `switch_inline_query_chosen_chat` с запросом `slug`: Telegram
предлагает выбрать чат, в поле ввода появляется `@бот Ab12Cd34Ef`, бот отвечает
карточкой.

Карточка в чужом чате: фото открытки (URL `og-image`, нужен публичный `BASE_URL`),
подпись — фраза, под ней кнопки:

```
[ 🎰 Сгенерировать свою ]   → t.me/<бот>?start=Ab12Cd34Ef
[ 🌐 На сайте ]             → BASE_URL/s/Ab12Cd34Ef
```

Inline-запросы:

| Запрос | Результат |
| --- | --- |
| пусто | 5 свежих фраз с тоном и словарём пользователя (`cache_time=0`, `is_personal`) |
| slug | эта фраза |
| название пресета («тайна») | 5 свежих фраз в этом пресете |

Inline-режим включается у BotFather (`/setinline`).

### Зал славы

`/top` и `/new` — карусель, одна фраза на сообщение, листание правит сообщение:

```
🏆 Зал славы · 3 из 50

Никто не знает, почему седой лоцман украл компас в библиотеке.

[ ◀ ] [ ❤️ 12 ] [ ▶ ]
[ 🎰 Взять за основу ] [ 🆕 Новое ]
```

- «Взять за основу» присылает фразу на главном экране со всеми закреплёнными словами
  (как `/?from=slug` на сайте).
- Листание назад требует смещения, а курсор ленты «новое» сейчас только вперёд.
  В `db.feed` добавляется `offset` и для `new` — при таком объёме ленты этого хватает.

### Команды и постоянная клавиатура

| Команда | Действие |
| --- | --- |
| `/start` | приветствие в две строки и первая фраза |
| `/start <slug>` | фраза по ссылке, все слова закреплены |
| `/spin` | новая фраза |
| `/top`, `/new` | зал славы, прямой эфир |
| `/help` | короткая справка: что делают кнопки |

Под полем ввода — постоянная reply-клавиатура `[ 🎰 Крутить ] [ 🏆 Зал славы ]`.
Любой другой текст тоже крутит фразу: бот не разговаривает, и лучший ответ на
«привет» — сюжет.

Команды регистрируются через `setMyCommands` при старте.

## Ошибки и лимиты

| Ситуация | Ответ |
| --- | --- |
| Лимит генерации (10/с) или лайков (30/мин) | подсказка «Не так быстро 🙂» |
| Слова фразы ушли из словаря (`Gone`) | подсказка «Эта фраза устарела» и новая фраза |
| Неизвестный slug, битый `callback_data` | подсказка «Фраза не найдена» |
| «message is not modified» при правке | игнорируется |
| Ошибка движка | «Не получилось собрать фразу», ошибка в лог |

На каждое нажатие бот отвечает `answerCallbackQuery` сразу — иначе у кнопки крутится
часик. Лимиты Telegram (1 сообщение в секунду на чат) с нашими лимитами не
конфликтуют.

## Конфигурация

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен от BotFather | не задан — бот выключен |
| `TELEGRAM_WEBHOOK_SECRET` | секрет заголовка webhook | генерируется и хранится в `DATA_DIR/tg_webhook_secret`, как соль |
| `TELEGRAM_MODE` | `webhook` / `polling` | `webhook`, если `BASE_URL` — HTTPS, иначе `polling` |

Токен на Railway задаётся переменной сервиса (секретом), не в `railway.ts`.

## План работ

Каждый шаг — отдельная ветка и PR, `main` остаётся рабочим.

1. **refactor:** сервисный слой `app/service.py`, роуты веба переходят на него.
   Поведение не меняется, тесты API проходят без правок.
2. **feat(bot): каркас** — конфиг, webhook и polling, `/start`, «Крутить», главный
   экран, `render.py`, таблица `tg_users`.
3. **feat(bot): слова, пресет, тон** — экраны и `callback_data` `l`/`r`/`v`/`p`/`t`/`x`.
4. **feat(bot): лайк, промпты, открытка.**
5. **feat(bot): зал славы** — карусель и `offset` в `db.feed`.
6. **feat(bot): inline-режим и «Поделиться»**, deep links `/start <slug>`.
7. **docs:** README (переменные, настройка BotFather: команды, `/setinline`), CHANGELOG.

Тесты: кодирование и разбор `callback_data` (включая длину ≤ 64 байт для самого
длинного slug и 8 слотов), клавиатуры, `render.py` (жирные закреплённые слова,
экранирование HTML), обработчики — через `Dispatcher.feed_update` с подменённым `Bot`.

## Решения, которые стоит подтвердить

1. **«Крутить» — новым сообщением, а не правкой старого.** Правка ближе к слот-машине и
   не засоряет чат, но затирает удачные фразы; новое сообщение превращает чат в
   историю находок. Рекомендую новое сообщение, а смену одного слова и закрепления —
   правкой.
2. **Имя бота** — нужен username для deep links и inline-режима.
3. **Голоса из бота и браузера считаются отдельно** — один человек может лайкнуть
   фразу дважды, с сайта и из Telegram.
